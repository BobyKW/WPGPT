# WPGPT - MCP Extensor & ChatGPT Connection

WPGPT is a WordPress plugin that extends **MCP Adapter** with secure WordPress abilities and an easier connection flow for **ChatGPT**, **VS Code**, and other MCP-compatible clients.

## What it does

- Extends MCP Adapter instead of replacing it
- Adds secure MCP abilities for WordPress diagnostics, content work, and technical inspection
- Lets you choose which WordPress user MCP runs as
- Generates a **Bearer token** flow for ChatGPT
- Generates a **WordPress Application Password** flow for VS Code, Cursor, and similar editors
- Shows copy-ready connection snippets in the admin panel

## Requirements

- WordPress 6.6+
- PHP 8.1+
- MCP Adapter installed and active

## Installation

1. Install and activate **MCP Adapter**.
2. Install and activate **WPGPT - MCP Extensor & ChatGPT Connection**.
3. Go to **Tools > WPGPT MCP Bridge**.
4. Select the WordPress user that MCP should use.
5. Save settings.
6. Generate the credential you need:
   - Bearer token for ChatGPT
   - Application Password for VS Code and similar editors
7. Copy the generated snippet into your MCP client.

## Connection modes

### ChatGPT
Use the Bearer token generated by the plugin together with the MCP endpoint shown in the admin screen.

### VS Code and similar editors
Use the generated Application Password snippet. This flow is tied to the selected WordPress user.

## Important note

WPGPT **depends on MCP Adapter**. It does not work as a standalone MCP server plugin.
